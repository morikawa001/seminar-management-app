MP4 SILENCE + AUDIO PROCESSOR

SilenceCut Pro

無音カット ＋ 語尾保護 ＋ 音量正規化 ＋ ノイズ除去を、ブラウザだけで完結。

01 // INPUT
MP4ファイルをドラッグ＆ドロップ
またはクリックして選択（.mp4 / .webm 対応）
02 // PRE TRIM
動画の最初から、この時刻までをカットします。
この時刻以降をカットします。未指定に近い状態なら末尾まで残します。
先に「PRE TRIM」で動画の前後を整えてから、その残り区間に対して無音カットを実行します。
03 // SILENCE CUT CONFIG
この音量以下を「無音」とみなします
この秒数以上の無音をカットします
無音開始の前を少し残す
無音終了の後から少し後に再開
語尾の消えかけの声を残す範囲
04 // AUDIO POST FX
音量正規化（ラウドネス均一化）
全体の音量レベルを統一します。場面によって音量が大きかったり小さかったりするムラを補正します。
YouTube推奨: -14 LUFS / 一般的: -16〜-18 LUFS
ノイズ除去（スペクトルサブトラクション）
背景の定常ノイズを除去します。無音区間の音声プロファイルを自動検出して差し引きます。
強度: 70%（強くしすぎると声質が変わります）
05 // ANALYZE & RENDER

検出された区間:

処理中...0%
ファイルを選択して、必要なら前後をトリムしてから「無音を検出」を押してください。

06 // EXPORT
動画をダウンロード

出力形式: WebM（.webm）。MP4に変換するにはClipchampやHandBrakeをご利用ください。
